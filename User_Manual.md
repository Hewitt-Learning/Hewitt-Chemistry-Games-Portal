# User Manual

This is the Ceiba Connections Game Portal. This use of this is to create a platform that provides educational games that are designed to help students learn through interactive activities across multiple subjects and age groups. This portal allows users to browse educational games by filtering though subject or age group, search for specific names, and view detailed game information. 

## Main Interface
The portal is divided into three main sections: the header for branding, the filter panel for searching and filtering tools, and the game grid for navigation and available games.

### Header Navigation

At the top of the portal, users will find a **Back to Main Page** button in the upper-left corner to return back to Hewitt-Learning's main website. To use this feature, a user will simply click the "Back to Main Page" and the system will redirect to the previous main page. 

### Game Search

The search bar is located on the left filter panel on the portal page. To use the feature the user needs to click on the inside of the search box, type the game title or a keyword, then matching games with automatically appear in the game grid. The purpose of this feature is to quickly find games by name. 

For Example:
- Typing "Decoder" shows:
    - Element Decoder
    - Compound Decoder

### Subject Filters

The subjects section allows users to filter games by educational category. Available subjects include: STEM, Language, History, Arts & Music, Math, Chemistry, and Biology. To use this feature a user will need to click on the checkbox next to a subject and the game grid will update to that category automatically. 

### Age Group Filters

The age group section helps users find games appropriate for student reading/learning levels. The available age groups include: 0-5 (pre-readers), 5–7 (early readers), 7–9 (transitional readers), 9–12 (intermediate readers), and 12+ (advanced readers). To use this feature is similar to the subject filter. A user will need to select their age group, then the portal will filter available games automatically. 

### Reset Filters Button

The **reset filters** button is used to clear all active filters. For a user to use this feature, one of the filters needs to be selected then click the **reset filters** button, and all subject and age filters will be removed from the search. The game grid will include the full game library again.

### Game Cards

Each game appears as an individual card within the game grid. The game cards contain game thumbnail/image, age recommendation, subject category, information button, and the game title. 

For desktop users:
- Hovering your mouse over a game card will display more game information.
- Clicking on the *i* button will toggle the game information.

For mobile users:
- Clicking on the *i* button will toggle the game information.
- Reclick the *i* button and the game information will go away.

## Launching a Game

For a user to launch a game, they must first locate the desired game card, click on the game image or title, and the game will launch in the application window.
